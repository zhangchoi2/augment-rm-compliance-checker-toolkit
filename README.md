# augment-rm-compliance-checker-toolkit

A toolkit for augmenting RM compliance checking.

## Upstream Projects

This project relies on the following upstream projects:

- [GAM](https://github.com/GAM-team/GAM) - Google Apps Manager
- [Open Images Dataset](https://github.com/openimages/dataset) - Large-scale image dataset
- [DECA](https://github.com/yfeng95/DECA) - Detailed Expression Capture and Animation
- [face.evoLVe](https://github.com/ZhaoJ9014/face.evoLVe) - High-Performance Face Recognition Library
- [Python Sample Project](https://github.com/pypa/sampleproject) - PyPA sample project template
